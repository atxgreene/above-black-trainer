# above-black-trainer

**Above Black: Line Training & Human Frequency Resonance System** — local-first PWA for frequency generation, resonance tuning, progressive training protocols, and now **Preset Modes** for focus, sleep, meditation & energy work.

## Features

- **Frequency Generator**: Real-time Web Audio with multi-band Hemi-Sync (binaural + isochronic), live visualizer, Energy Body overlay.
- **Resonance Tuner**: Harmonic layering for biological coherence.
- **Training Lines**: 4 progressive protocols (Foundation, Activation, Integration, Transcendence).
- **Gateway Protocols**: Full Monroe Institute-inspired Focus 10–27 states with specific frequencies and durations.
- **Energy Body Mastery**: Chakra activation, circulation, expansion, shielding, patterning with intention setting.
- **Analytics**: Session tracking, coherence trends, exportable reports, streak counter.
- **NEW: Preset Modes Tab**: One-click optimized configurations for:
  - Deep Focus • Reading & Study (40 Hz Gamma + 14 Hz beta)
  - Deep Work • Flow State (528 Hz + 18 Hz beta)
  - Sleep Onset • Wind Down (432 Hz + 4 Hz theta)
  - Deep Sleep • Delta Restoration (174 Hz + 1.5 Hz delta)
  - Alpha Calm • Light Meditation (432 Hz + 10 Hz alpha)
  - Theta Journey • Deep Meditation (639 Hz + 6 Hz theta)
  Each preset dynamically sets base frequency, binaural beat rate, isochronic pulse rate, loads into Generator, enables Hemi-Sync, starts playback, and runs session timer with logging.

## Tech
- Single-file HTML + Tailwind + Font Awesome + Chart.js
- Web Audio API for synthesis (no external audio files)
- Fully offline-capable PWA (service worker + manifest)
- LocalStorage persistence for progress, energy level, settings, intention
- GitHub Pages deployment
